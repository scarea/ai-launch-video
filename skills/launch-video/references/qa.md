# 质检

```bash
npm run qa -- <id>          # 报告写到 runs/<id>/qa.json，有 ✗ 时退出码为 1
```

| 检查 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 稿件格式与引用 | 无错误；提醒项逐条看 | 按提示改 episode.json |
| 编码 | h264 1920×1080，有音轨 | 重新 render |
| 时长 | 类目建议范围（ai-model-launch：5–7 分钟） | 删句/删章，不加速 |
| 音量 | 平均 -24～-14dB，峰值 ≤ -0.5dB | 确认 tts 后处理含 loudnorm，重跑 tts（只重处理不重合成）+ assemble + render |
| 字幕同步 | 声音相对字幕中位数 ≤ 120ms | 确认 tts 裁掉了首尾静音 |
| 全片解码 | 无错误 | 重新 render |

## 人工项（报告不能替代）

- **看检查帧**（`npm run stills`）：高亮是否圈中、推近后是否可读、主播是否被遮挡、字幕是否一行
- **试听**：英文模型名、数字、单位的念法；不对就改 episode.json 的写法再重跑 tts
- **事实复核**：抽查 5 条带数字的句子，对照 facts.json 的 `exact`

交付时如实告诉用户做了哪些检查、哪些没做（尤其是否完整试听）。
