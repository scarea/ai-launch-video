# 画面、推近与高亮坐标

## 坐标系

`focus`、`focusFrom`、`highlight` 全部是**相对原图**的 0–1 坐标：
- `focus: [x, y, w, h]`：镜头最终框住的区域；`focusFrom` 为起始区域（缺省为整张图）
- `highlight: {x, y, r}`：高亮圈中心，`r` 为图片宽度的比例（数据点用 0.03，表格单元格用 0.05–0.06）
- 模板会按图片真实比例放进 1380×676 的主画面，并保证镜头不露出图片外的空白

高亮点必须落在 `focus` 区域内（校验会提醒）。

## 测坐标：一律用 locate，不要目测

```bash
npm run locate -- <图片> --grid out/grid.jpg         # 1. 看带网格的预览，确定大致区域（out/ 不提交）
npm run locate -- <图片> --sample 0.69,0.26          # 2. 读数据点颜色
npm run locate -- <图片> --color '#629987'           # 3. 找该颜色所有色块，输出中心 x/y、顶部 top、宽高
```

- 折线图数据点：用该系列颜色找色块，按 x 排序对应档位（Low → Max）
- 柱状图：柱子色块的 `x` 是中心，`top` 是柱顶；高亮放在 `(x, top - 0.02)`
- 表格：用 `--grid` 读行列位置，单元格中心手算（表格没有颜色可找）；也可找高亮列的底色
- **禁止**在缩放、拼接过的预览图上量坐标再换算，这是最常见的错误来源

## 推近

- 第一句展示整张图（或图表主体区域），下一句再 `focusFrom → focus` 推到要讲的点
- 长表格（高 > 宽）：用 `focus: [0, y, 1, h]` 横向占满，`h` 取 0.2–0.33；换行讲另一段时用 `focusFrom` 接着上一个 focus 平移
- 图表下方的英文说明文字通常不需要露出，focus 避开它

## 检查

`npm run stills -- <id>` 会在每个画面段中点抽一帧。逐张确认：高亮圈套中目标、推近后文字可读、没有遮挡主播。
要检查指定帧：`npm run stills -- <id> --frames=1200,3400`。
